# 项目文档

当前正式版：[2.0.0](releases/v2.0.0.md)，已发布并设为 [Latest](https://github.com/wenchenyang874-a11y/tts_2_datasets/releases/tag/v2.0.0)。包含[声音复刻、音色设计和自定义音色管理](product/custom-voices.md)、现场参考录音与朗读文稿、独立类型交叉筛选。三项远端资产完整回读核验通过，用户明确豁免本次 Win10 实测门槛，仍如实标明 Win10 未实测。

beta.8 未单独发布，其已验收功能提升为正式版 2.0.0；[beta.8 验收记录](releases/v2.0.0-beta.8.md)和[测试说明](testing/custom-voices-beta8.md)保留原构建及验证范围。小米 332 秒单次延迟的具体慢因仍未查明，未将正式发布描述为该事项已修复。

历史版本：[2.0.0-beta.7](releases/v2.0.0-beta.7.md)，创作工作区与跨供应商选择重做，移除自动音频去重；同版本继续修复页签误弹帮助、筛选文字裁切及共享下拉框闪刷／圆角，并让单击音频自动更新波形与频谱。崩溃诊断的已知证据和未决项见测试／开发状态。

上一发布版本：[2.0.0-beta.6](releases/v2.0.0-beta.6.md)，包括滚轮防误改、任务阅读位置保留和样本单选／多选／逐行播放／右键直接 WAV 导出；修复按钮裁切、合并操作工具栏并增加图表坐标。Windows 11 实际窗口和隔离安装验收完成，三项资产完整回读校验通过；按用户要求设为 Latest，GitHub 预发布标记取消，beta 版本号与原产物保留。

上一发布版本：[2.0.0-beta.5](releases/v2.0.0-beta.5.md)，包含样本整行即时选择、音色分层展示与表达控制；历史发布及验证记录保留。

Windows 原生桌面版本已由用户合入 main，后续直接在 main 开发；Web 基线保留在备份分支。Windows 10 尚待实测；以后每版先交付本地安装包，收到用户验证通过和明确发布通知后再发布并一并设为 Latest，平台标记不改变验证范围。未发布期间沿用版本号，发布后开始下一版时才递增。使用者先看产品规范与桌面使用，维护人员再看架构、状态和验证要求。
