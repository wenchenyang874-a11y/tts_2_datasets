# 2.0.0-beta.6 本地验收版本

本版基于已发布的 beta.5，在 main 开发；仅本地提交、构建和验证，等待用户验收具体安装包后明确通知发布。不创建 Tag 或 Release，不改变 beta.5 已发布资产及 Latest 状态。

## 改动

- 移除费用责任常驻勾选框；云批次继续在预检后用弹窗明确确认。
- 下拉框、数字填写框和可编辑文本框禁止滚轮误改，聚焦时也一样；页面继续滚动，独立弹窗保持数值，键盘和按钮操作保留。
- 修复任务技术详情周期刷新回到顶部；保留滚动位置与文本选区。
- 样本默认单击切换当前行；进入“多选”才显示勾选框、批量按钮并累积选择，退出清空批量选择。
- 每行提供 40×34 播放／停止按钮，移除下方统一“试听”按钮，双击播放保留。
- 右键提供播放、频谱分析、审核子菜单、删除与“导出音频文件…”。单条导出选择目录后直接复制 WAV，已有同名文件保留；与训练集打包区分。
- 豆包 2.0 指令能力改为依据官方逐音色声明。未标注音色显示“未标注指令”并在生成前提示，避免将整个模型误标为支持。
