# 2.0.0-beta.6 本地验收版本

本版基于已发布的 beta.5，在 main 开发；仅本地提交、构建和验证，等待用户验收具体安装包后明确通知发布。不创建 Tag 或 Release，不改变 beta.5 已发布资产及 Latest 状态。

## 改动

- 移除费用责任常驻勾选框；云批次继续在预检后用弹窗明确确认。
- 下拉框、数字填写框和可编辑文本框禁止滚轮误改，聚焦时也一样；页面继续滚动，独立弹窗保持数值，键盘和按钮操作保留。
- 修复任务技术详情周期刷新回到顶部；保留滚动位置与文本选区。
- 样本默认单击切换当前行；进入“多选”才显示勾选框、批量按钮并累积选择，退出清空批量选择。
- 每行提供 40×34 播放／停止按钮，移除下方统一“试听”按钮，双击播放保留。
- 右键提供播放、频谱分析、审核子菜单、删除与“导出音频文件…”。单条导出选择目录后直接复制 WAV，已有同名文件保留；与训练集打包区分。
- 豆包 2.0 指令能力改为依据官方逐音色声明。未标注音色显示“未标注指令”并在生成前提示，避免将整个模型误标为支持。

## 验证范围

Windows 11 x64 / 10.0.26200，本地 208 项离线回归通过，1 条既有上游弃用提示。新增 Qt 控件回归覆盖聚焦／子控件／像素滚轮、动态弹窗、只读日志、任务位置及选区、单选／多选、逐行播放、右键稳定 ID 和直接 WAV 导出。同名旧文件保留，云确认取消不提交任务，确认后只授权预检快照。

`artifacts/beta6-ux-20261014-source-150-v6/result.json` 为 ok=true，31 项原生流程通过，包括 150% 实际窗口、悬停、下拉列表、七页填写框滚轮、任务阅读位置、两种样本模式、右键菜单和审核子菜单截图、单个 WAV 导出。早期失败证据保留，不作为通过依据。

用户另行授权的豆包 ASMR 对照仅执行 2 次真实请求，无自动重试，结果只存入隔离 artifacts，不写入用户数据集，凭据文件哈希不变。两份有效 WAV 不同，请求中的指令与官方 additions.context_texts 格式一致；用户听辨为“有差异，但不符合预期”，因此不宣称 ASMR 风格问题已修复。官方能力分类误标已修正，真实听感仍待确认；不把离线流程的 real_cloud_verified=false 改写为全面云验收成功。

Windows 10、真实麦克风仍待实测。构建、安装、实际资产哈希在本文件继续补齐；包未代码签名，用户现有安装通过隔离夹具保护。
