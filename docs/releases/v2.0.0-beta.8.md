# 2.0.0-beta.8 本地验收版本

此为未单独发布的 beta.8 历史验收记录；其功能已于 2026-10-15 纳入 [2.0.0 正式版](v2.0.0.md)并发布为 Latest。下文产物与测试结论对应各 beta.8 构建，不能替代正式包的记录。

## 改动

- 新增“我的音色”，统一声音复刻、文本音色设计与自定义音色管理。
- 复刻参考音频新增现场录制：麦克风选择、实时电平、停止、播放检查、重录与使用；豆包/小米直接采用录音，阿里云先保存 WAV 再填写公网链接。取消保留旧参考，录音不自动上传、不进入样本库。
- 录音窗口持续显示可编辑的中／英文朗读文稿，重录与取消均保留本次创建窗口中的文稿草稿。
- 音色目录增加独立类型交叉筛选，区分预置、复刻、设计、其他自定义，并在行内标注；类型与其他条件取交集，不清空已选。
- 豆包使用 V3 API 和已购买 Speaker ID；1.0/2.0 绑定独立资源与密钥。复刻 2.0 填写指令时使用表现力增强推理版本。
- 小米使用官方设计/复刻模型，参考音频保存在数据目录并供后续复用。阿里云接入 CosyVoice，复刻使用公网 HTTPS 音频，设计使用北京地域。
- 列表预览、名称/标签、启停、状态查询、云目录导入与本地移除；可用音色直接加入合成已选列表。
- 后台任务、防误重试、结果未知与状态查询；参考/预览随数据目录即时迁移。保持声源分组，避免真人与复刻、不同模型及不同供应商泄漏。

使用入口见[我的音色](../product/custom-voices.md)，实现边界见[架构说明](../architecture/custom-voices.md)，验证与未验证项见[beta.8 测试](../testing/custom-voices-beta8.md)。
