# 2.0.0-beta.5 本地验收版本

本版仅本地提交与构建，等待用户验收后明确通知发布。没有 Tag、推送或 Release，main 与 Web 备份不变；此前 beta.4 已公开状态不构成本版授权。

## 变化

- 固定下拉列表的位置与宽度，统一白色／淡紫样式；修复即时切换页面后的重复打开，保留鼠标和键盘选择。
- 音色名称、性别／年龄、语言与能力标签分层展示；整行点击或空格键勾选，选中不会缩进。
- 增加中文／外语／未知语言与指令／情感能力筛选；豆包、小米及阿里云按具体模型／音色的官方能力控制表达。
- 点击合成立即检查指令／情感冲突，弹窗列出音色并保留整个表单，不等任务执行后报错。
- 样本双击直接播放，停止控制只在试听页面播放时出现；切换页面停止并取消未完成试听。
- 样本选择列收窄、长来源选中后继续完整换行；窄窗口上下排列合成卡片。
- 用户继续验收后，取消样本库独立选择列：勾选框直接位于文本左侧，整行单击勾选／取消，双击选中并播放；移除错位的默认命中区域和空白焦点格。未发布前继续使用 beta.5，不递增版本号。
