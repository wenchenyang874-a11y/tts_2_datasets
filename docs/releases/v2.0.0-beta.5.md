# 2.0.0-beta.5 本地验收版本

本版仅本地提交与构建，等待用户验收后明确通知发布。没有 Tag、推送或 Release，main 与 Web 备份不变；此前 beta.4 已公开状态不构成本版授权。

## 变化

- 固定下拉列表的位置与宽度，统一白色／淡紫样式；修复即时切换页面后的重复打开，保留鼠标和键盘选择。
- 音色名称、性别／年龄、语言与能力标签分层展示；整行点击或空格键勾选，选中不会缩进。
- 增加中文／外语／未知语言与指令／情感能力筛选；豆包、小米及阿里云按具体模型／音色的官方能力控制表达。
- 点击合成立即检查指令／情感冲突，弹窗列出音色并保留整个表单，不等任务执行后报错。
- 样本双击直接播放，停止控制只在试听页面播放时出现；切换页面停止并取消未完成试听。
- 样本选择列收窄、长来源选中后继续完整换行；窄窗口上下排列合成卡片。

## 验证与产物

源代码 150% 缩放的 25 项 Windows 11 原生流程通过。完整测试／构建／冻结／隔离安装证据和产物哈希在构建后补齐；见 [验收文档](../testing/windows-validation.md)。

预期本地产物目录 `dist/releases/2.0.0-beta.5/`，安装包 `TTS-Dataset-Studio-2.0.0-beta.5-windows-x64-setup.exe`。交付前必须检查实际文件及清单，不能以本节预期名称当作已构建证据。

Win10、真实云账号、人声表达效果和真实麦克风仍待验证，不合入 main。按[使用说明](../product/windows-quickstart.md)配置及操作；用户现有安装和数据由隔离安装验证保留。
