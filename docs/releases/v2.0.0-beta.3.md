# TTS Dataset Studio 2.0.0-beta.3

本地验收版本，未打 Tag、未上传或创建 GitHub Release。等待用户验证安装包通过并明确通知发布。

- 重构主窗口、合成、设置和任务界面，采用紧凑卡片、独立服务选择、音色搜索/全选与批次摘要；高级参数默认收起。
- 数据目录选择后自动保存并即时使用，不需要重启；空目录由使用者选择迁移现有数据或使用空数据集。迁移完成后移除旧位置对应应用数据，未知文件不动；失败恢复原目录。
- 豆包 1.0/2.0 独立配置、音色筛选与估价；创建任务前检查相应凭据，缺少时给出“去配置”入口。
- 使用 Base URL 标签与官方默认值，自动补齐请求路径。任务页直接显示失败原因，技术 JSON 默认收起。
- 按用户要求不处理旧配置、旧版本兼容。

用户反馈的合成失败已从本地任务库只读查证：选中豆包 2.0 音色，但未填写 2.0 API Key，失败发生在云请求之前；并非已查证的网络故障。凭据仍需使用者在独立服务页填写，格式预检不能证明实际账号权限。

目标为 x64 Windows 10 1809 及以上、Windows 11；当前仅 Windows 11 实测，真实云、真实麦克风和 Win10 待验证。开发分支保留，main 与 Web 备份不变。当前包未代码签名。
