# TTS Dataset Studio 2.0.0-beta.2

- 增加小米 MiMo 开放平台预置音色合成，支持官方 9 款预置音色、风格指令与 WAV/MP3。
- 支持豆包语音 2.0 V3 HTTP 合成，使用独立 API Key；保留 1.0，增加模型筛选及音色版本标识。
- 设置中选择、输入并保存数据目录，下次启动生效；旧数据保留原位，命令行 --data-dir 优先。
- 修复带圈问号悬停帮助，支持键盘聚焦及移出收起；验收使用实际鼠标命中控件。
- 保存供应商配置后自动获取音色列表，合成创作提供醒目的紫色“获取音色列表”。
- “验证格式”检查当前未保存表单，保留已存密钥；不保存配置、不调用云端，不固定返回成功。
- 移除设置中的“导入 Web 备份到新目录”入口。

小米目录为官方预置快照，不代表账号合成权限。豆包远程目录查询需要独立 AK/SK；未配置时加载维护的官方预置目录。

目标为 x64 Windows 10 1809 及以上与 Windows 11。当前验证限于 Windows 11、隔离安装身份与离线/模拟 HTTP 协议；真实云、真实麦克风和 Windows 10 尚待实测。原已安装应用和用户数据保持原状态，main 与 Web 备份未修改，继续发布为非 Latest 预发布。

下载 `*-setup.exe` 安装，或解压完整 `*-portable.zip` 运行，使用 `SHA256SUMS.txt` 核对完整性。安装包未代码签名；安装升级前需关闭旧应用。

使用与配置见[桌面使用指南](https://github.com/wenchenyang874-a11y/tts_2_datasets/blob/feature/windows-native/docs/product/windows-quickstart.md)。小米和豆包请求契约分别依据 [MiMo TTS 官方文档](https://mimo.mi.com/docs/zh-CN/api/audio/tts)与[豆包 V3 官方文档](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)。
