# TTS Dataset Studio 2.0.0-beta.4

本地待用户验收版本，不创建 Tag、Release 草稿或上传资产。

- 豆包 1.0/2.0 均使用新版语音控制台 API Key 和 V3 HTTP 单向流式接口，设置与音色选择继续分开；不保留旧合成鉴权回退。
- 移除供应商地址输入框。火山、小米地址内置；阿里云选择华北2（北京）或新加坡，程序按地域及可选 Workspace ID 生成合成和音色查询地址。
- V3 WAV 改为拼接 PCM 后生成完整文件，失败或未完成的分段不能作为成功音频入库。

当前预发布阶段不转换旧配置。豆包 1.0 需在独立设置页填写 API Key；高级“复刻应用 ID”仅用于查询账号复刻音色，合成不需要。
