## 改动

- 合成创作重做为无需整页滚动的三栏工作区：文本／表达／参数／音频页签、大音色目录、持续可见的已选栏与批次操作。
- 支持跨供应商选择，浏览和筛选保留已选；可从已选栏定位／移除音色，逐供应商配置请求音频，全局参数按共同能力开放。
- 提交后保留创作内容，不强制跳入任务中心。
- 删除合成、录音导入、增强与背景样本的自动复用／音频去重。每份独立入库，任务统计只计真实完成和失败，相同哈希仍可有不同样本。
- 新增本地原生异常诊断，不记录请求内容、指令或密钥；本轮崩溃根因仍待捕获调用栈，不能宣称已修复。
