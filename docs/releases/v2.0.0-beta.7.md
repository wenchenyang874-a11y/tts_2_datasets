# 2.0.0-beta.7 本地验收版本

当前未发布，不创建 Tag／Release；等待用户验证具体构建后明确通知发布。

## 改动

- 合成创作重做为无需整页滚动的三栏工作区：文本／表达／参数／音频页签、大音色目录、持续可见的已选栏与批次操作。
- 支持跨供应商选择，浏览和筛选保留已选；可从已选栏定位／移除音色，逐供应商配置请求音频，全局参数按共同能力开放。
- 提交后保留创作内容，不强制跳入任务中心。
- 删除合成、录音导入、增强与背景样本的自动复用／音频去重。每份独立入库，任务统计只计真实完成和失败，相同哈希仍可有不同样本。
- 新增本地原生异常诊断，不记录请求内容、指令或密钥；本轮崩溃根因仍待捕获调用栈，不能宣称已修复。

## 验证边界

223 项本地离线测试通过；[构建源 CI](https://github.com/wenchenyang874-a11y/tts_2_datasets/actions/runs/38527809240) 成功（218 通过、5 项 Windows 专属跳过）。Windows 11 源码 100%／150%、冻结 150% 与安装后 150% 均通过 35 项原生流程，最小窗口各页签和已选栏截图已核对；隔离安装通过 9 项检查，普通锁定启动与凭据外部诊断日志正常关闭。测试注册已卸载，现有生产安装未覆盖。详细证据见 [验收记录](../testing/windows-validation.md)。

Windows 10、真实麦克风和跨供应商真实云整批合成未验收。旧版 ASMR 听感问题的边界不变。崩溃定位的 200 次离线循环及单次成功的真实小米提交仍未复现原故障；首个获准小米请求因测试脚本判断错误被中断，结果未知，没有自动重试。原设置读取器触发凭据文件重封装与更新时间变更，未调用原配置更新接口；不能将该文件记录为哈希未变。测试过程的不足与未决项已保留。
