## 同版本控件修复

用户进一步报告页签切换后的常驻帮助、筛选末字裁切、各页面下拉闪刷与右下角方形残留，均已复现并修复。参数／音频页签只在真正悬停或键盘查看时弹帮助，筛选按实际字体完整显示，共享下拉弹窗定位完成后只显示一次；窗口角实际透明，白色卡片边沿保持完整。样本单击切换后自动更新波形、频谱与指标，快速切换不被旧结果覆盖，移除当前音频时清空。波形保留真实正负振幅，以 0 居中。旧 91af0a8、306db43、6e6d589 和 d32c955 产物已按源提交归档至 `dist/releases/archive/2.0.0-beta.7/`；以下表为新的 7911785 构建，沿用 beta.7，不发布。

## 改动

- 波形显示真实有符号 PCM 峰值，0 居中、纵轴 -1–1，保留尾部短脉冲和真实采样时间。
- 样本单击切换后自动后台分析，支持多选模式与键盘当前行，错误与结果按稳定 ID／generation 过滤。
- 下拉圆角采用透明窗口和抗锯齿白色卡片，移除方形系统阴影；保留完整边沿与定位、键盘、滚轮行为。
- 合成创作重做为无需整页滚动的三栏工作区：文本／表达／参数／音频页签、大音色目录、持续可见的已选栏与批次操作。
- 支持跨供应商选择，浏览和筛选保留已选；可从已选栏定位／移除音色，逐供应商配置请求音频，全局参数按共同能力开放。
- 提交后保留创作内容，不强制跳入任务中心。
- 删除合成、录音导入、增强与背景样本的自动复用／音频去重。每份独立入库，任务统计只计真实完成和失败，相同哈希仍可有不同样本。
- 新增本地原生异常诊断，不记录请求内容、指令或密钥；本轮崩溃根因仍待捕获调用栈，不能宣称已修复。
