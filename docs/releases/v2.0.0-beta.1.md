# TTS Dataset Studio 2.0.0-beta.1

首个 Windows 原生桌面预发布版。面向 x64 Windows 10 1809 及以上、Windows 11；当前已完成 Windows 11 离线验证，Windows 10 尚待实测，继续保留 `feature/windows-native`，main 与 Web 备份保持原状态。

- 原生七页面：批量合成、样本审核/分析/试听、录音与音频导入、噪声增强、任务、训练集导出、设置。
- 简约界面，必要解释通过相关控件旁的带圈问号悬停显示。
- 用户数据与程序分离，云凭据由 Windows 当前用户 DPAPI 保护，支持旧 Web 数据复制导入。
- 提供无需管理员权限的安装包与包含 Python/Qt/FFmpeg 的便携包；升级和卸载保留数据，运行中阻止升级/卸载，拒绝降级。
- 保留 16 kHz mono PCM16 WAV 与训练分组隔离契约，云调用显式确认费用。

下载 `*-setup.exe` 安装，或解压 `*-portable.zip` 并保留完整目录后运行。`SHA256SUMS.txt` 用于检查下载完整性。产物未代码签名。

Windows 10、真实麦克风采集与设备拔插、真实云合成和人耳听感仍待验证；Mock 检查不能代表真实云或录音成功。

使用与配置见[桌面使用指南](https://github.com/wenchenyang874-a11y/tts_2_datasets/blob/feature/windows-native/docs/product/windows-quickstart.md)。问题请通过仓库 Issues 反馈。
