# 2.0.0 正式版

2026-10-15，基于用户已验收的 beta.8 功能构建；正式版本号为 `2.0.0`，Windows 数字版本 `2.0.0.65535`，高于同版本 beta。只调整版本与发布工具／文档，应用业务及界面与 beta.8 构建 b3a676b 一致。

## 功能

- Windows 原生桌面创作、样本库、录音、增强、任务与数据集导出。
- 小米 MiMo、豆包 1.0／2.0、阿里云供应商配置及跨供应商音色选择。
- 声音复刻、音色设计与自定义音色管理；参考音频现场录制，含可编辑的中／英文朗读文稿。
- 音色类型独立交叉筛选，区分预置、复刻、设计和其他自定义；切换筛选保留已选。

## 验证范围与已知事项

沿用已验收功能的针对性回归及历史验证，来源见 [beta.8 测试说明](../testing/custom-voices-beta8.md)。版本提升只核对版本映射、发布门槛、产物和 Windows 11 普通启动，不重新执行完整业务测试或安装矩阵。

Windows 10 尚未实际运行验证，不能将正式版号或 Latest 状态理解为 Windows 10／11 双系统验收完成。豆包／阿里云自定义音色真实账号调用与主观相似度仍待验证。

小米曾有一笔任务在等待 HTTPS 响应正文时耗时 332 秒后成功；后续相同输入的诊断 4.415 秒成功，具体慢因未查明。声音创建和合成不自动重试，避免未知结果时重复计费。

## 产物

安装包、便携包和 `SHA256SUMS.txt` 输出到 `dist/releases/2.0.0/`；构建清单及最终哈希在发布后登记。Windows 10 发布门槛的处理必须单独记录，不伪造测试报告。
