# 我的音色

beta.8 新增声音复刻、音色设计和自定义音色管理。只有状态为“可用”且启用的音色才能进入合成目录。

## 创建与使用

1. 在设置保存所选供应商的 API Key。阿里云先选择正确地域和 Workspace；声音设计使用北京地域。
2. 打开“我的音色”，选择“声音复刻”或“设计音色”，填写名称、供应商及对应字段。
3. 豆包填控制台已购买的 Speaker ID；创建可能覆盖该云端槽位并消耗次数。豆包和小米可选择本地参考音频，也可点“现场录制”：选麦克风、开始和停止录音，播放检查后“使用这段录音”；不满意可重新录制。取消不会替换原参考文件。阿里云 CosyVoice 需要公网 HTTPS 音频链接；“现场录制”可先保存 WAV，再由你上传并填写链接。应用不替你把本地文件发布到公网。
4. 复刻推荐清晰单人录音；本地导入限制 3–60 秒、10 MB。现场录音不足 3 秒不能使用，60 秒自动停止；录音不会自动上传或加入样本库，只有创建确认后才提交供应商。小米 Base64 编码后也不能超过 10 MB。豆包 2.0 官方建议 14–30 秒，阿里云建议 10–20 秒。
5. 设计填写声音描述与预览文本。确认云操作后提交一次，后台创建；可离开页面。失败或超时不会自动重发。阿里云复刻不额外发起预览合成；其他创建接口附带预览。
6. 如果显示“待审核 / 训练中”，选择音色后点击“刷新音色状态”。若结果未知先查询供应商控制台与状态，避免重复付费创建。
7. 点每行预览按钮播放已保存音频。“用于合成”会加入创作页的已选列表并定位音色，可与其他供应商一起选择。

小米没有持久云音色 ID：参考音频由应用保存。设计后的预览也作为后续复刻参考，之后合成通过 `mimo-v2.5-tts-voiceclone` 复用声音。删除或移动参考文件会导致不可用，应通过设置切换整个数据目录。

## 管理

- “编辑音色”修改本地名称、标签与启用状态；目录同步不会覆盖这些本地设置。
- “同步云端音色”导入账号已有音色；供应商账号查询权限与合成权限不同，缺少权限会提示。
- “移除音色”只移除本地列表项，不删除已生成样本、不销毁云端音色或购买的槽位。
- 勾选“显示已移除”可以选中原记录并“恢复音色”；云音色恢复后须主动刷新状态，不会重新训练或创建。
- 同一人不同录音、跨供应商复刻，填写相同“声源标识”；可以使用真人录音的说话人 ID。相同本地文件自动关联，同一声源在数据集划分时保持同组。
- 数据目录迁移包含参考与预览文件，无需重建音色。阿里云音色绑定模型、地域和 Workspace；更改地域后要恢复对应设置才能使用原音色。

供应商规则与 API 依据见[自定义音色架构](../architecture/custom-voices.md)。离线测试生成的是测试音调，不代表真人音色相似度或云端权限已验证。
