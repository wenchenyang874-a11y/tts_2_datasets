# Windows app 需求与 UI 规范

## 2.0.0-beta.7 创作工作区（2026-10-14）

- 不自动复用、跳过或丢弃相同音频。每份合成实际调用供应商并独立入库；相同文件再次导入、重复增强和背景样本创建也保留独立样本。SHA-256 仅用于完整性与导出，不作为拒绝入库依据。失败调用不自动重试。
- 合成页不提供整页滚动：左侧以文本／表达／参数／音频页签填写，中间为可伸缩的大音色目录，右侧持续显示已选音色。列表和长文本仅在自身区域滚动。最小窗口内所有页签和提交按钮必须完整可见。
- 音色可跨供应商累积选择；切换供应商、语言、能力及搜索不清空选择。已选栏展示名称与供应商，可移除或定位原音色。批次数量始终对应全部已选音色。
- 请求音频格式按供应商分别设置；全局参数仅开放所有已选供应商共同支持的项。表达冲突在开始前明确提示，不丢草稿。提交后保留创作页，用户按需进入任务中心。
- 本轮用户报告“开始合成”后原生崩溃；日志与离线复现结果分别记录，不把无法复现或补充诊断当作已查明／修复根因。

## 2.0.0-beta.6 交互增补（2026-10-14）

- 移除云费用责任常驻勾选框；本次云批次仍通过确认弹窗明确确认。
- 全部下拉框和可编辑填写框禁止滚轮改值／内部滚动截留，聚焦时同样处理；页面继续滚动，键入、箭头按钮及键盘操作保留。只读任务日志可滚动，自动刷新保留其位置与文本选区。
- 样本默认单击切换唯一当前行，不勾选；“多选”按钮切换后才显示选择框，单击累积勾选，退出多选清空批量选择。
- 每个样本音频有易点击且美观的播放按钮，删除统一“试听”按钮；双击播放保留。
- 播放按钮在首次显示、列宽变化、多选切换及窗口缩放后均完整可见，底部点击区域有效。音频分析、审核、编辑和撤销操作与筛选／多选在同一工具栏，空间不足才换行，不再占用表格下方一行。
- 波形有时间（秒）／振幅坐标，频谱有频率／dB 坐标及少量刻度、淡色网格；使用真实音频时长及频率，不以点序号冒充物理坐标。
- 右键菜单包括播放、频谱分析、审核子菜单（未审核／已通过／已拒绝）、删除和“导出音频文件…”。选目录后只导出单个 WAV，保留同名旧文件；与训练集 ZIP／清单导出区分。
- 豆包 2.0 指令能力逐音色依据官方声明；未标注音色不得直接宣称支持。自然语言 ASMR 指令无需额外加 #，请求参数正确不代表实际听感已达预期。

## 已确认的目标

项目从现有局域网 Web 工具迁移为 Windows 原生桌面应用，支持 Windows 10 和 Windows 11。原生界面不能以网页套壳、WebView 或自动打开浏览器替代。最终沿用主分支 `main`，不是 `master`。

初始化阶段已完成克隆、Web 分支备份、Windows 开发分支和项目规则。用户于 2026-10-13 已将 PR #16 合入 main，并要求后续直接在 main 开发、验证；实际产物和系统验证状态见开发与测试文档。

## 功能与数据契约

迁移前以现有源码、测试及 Web 文档逐项建立功能对照，保证以下能力不因替换界面丢失：

- 火山引擎、阿里云配置与音色查询，供应商/性别/年龄筛选。
- 多文本、多音色批量合成，参数校验、真实并发、父子任务、状态、耗时和预估费用。
- 本机麦克风录音、停止、试听、重录、导入；连续导入保留文本、说话人和标签等参数。
- 音频播放、波形、频谱、时长、峰值与 RMS 分析。
- 样本分页、搜索、跨页选择、元数据、正负/背景语义、审核切换、软删除和恢复。
- 背景噪声管理、确定性 seed 与 SNR 增强；增强结果重新进入未审核状态。
- 通用 JSONL、分类目录和 WeKWS 导出，按说话人或供应商音色分组隔离 Train/Dev/Test；基础样本与增强版本不跨组。

入库和训练导出音频保持 16 kHz、单声道、signed 16-bit little-endian PCM WAV。清单字段、标签和 WeKWS 文件结构依照现有业务契约，不能以 UI 重写为由静默改变。迁移现有数据库和音频前完整备份，兼容旧数据并保留回滚能力。

云调用继续要求显式费用确认，金额标为预估费用；未配置价格不显示成零费用。可能计费的合成请求不做隐式自动重试，失败项经使用者确认后显式重试。自动化测试使用 Mock，真实云验证需用户授权并限制调用规模。

## UI 硬要求

界面简约、现代、美观，不使用陈旧、拥挤的视觉。字体、色彩、图标、留白、控件和对齐统一；信息层级清晰，以当前操作的输入、结果和主操作为中心。

不要把多余解释性文字写在 app 上。必要解释、输入要求和参数边界放在相关内容旁的带圈问号（`？`）中，鼠标移上去显示解释或要求；键盘聚焦也应能读取。提示紧邻关联内容，清晰可读，不靠大量常驻说明撑满界面。

控件标签和任务状态保持简短清楚。实际输入错误、任务失败、正在处理状态，以及必须显式确认的云费用在对应操作处明确呈现，不能仅藏在悬停帮助内。长时间操作不能卡住窗口，也不能伪造成功状态。

界面验收检查真实截图和操作，涵盖不同窗口尺寸、Windows DPI 缩放、中文内容较长及列表数据较多的情形。具体配色和桌面框架在后续设计中确定，本需求不预设未经确认的技术方案。

## 开发前需明确的兼容范围

用户已确认 x64 Windows 10 1809 及以上、Windows 11，采用 Qt/PySide6 原生控件并复用 Python 业务，提供包含运行依赖的便携包。该支持目标仍需分别实测，不以框架支持表替代项目验收。具体方案见架构文档。

本机数据与凭据不放入安装目录；记录可配置数据目录、访问保护、旧 Web 数据导入和备份恢复方案。源码或共享脚本不能写死开发者的本机路径。系统验收门槛见 [Windows 验证与发布门槛](../testing/windows-validation.md)。

## 安装与版本发布

用户于 2026-10-13 要求提供 Windows 安装包，并调整为先本地提交、构建和交付用户验证；用户验证通过并明确通知发布后，才为该版本打 Tag 并上传 GitHub Release。Agent 不得自行发布，包括提前创建 Tag 或 Release 草稿。安装包与便携包包含运行依赖；安装、升级和卸载保留用户数据与凭据。后续直接在 main 开发；Win10 尚待实测时获准发布的版本仍为非 Latest 预发布，Web 备份固定保留。版本与发布约定见发布文档。

## 2.0.0-beta.2 需求增补

- 增加小米 MiMo 开放平台预置音色合成，用户已明确服务类型。
- 豆包语音保留 1.0，并支持 2.0 的 V3 接口、独立 API Key 和模型区分。
- 设置提供自定义数据目录选择、输入和保存，下次启动生效；保留原目录数据，不自动搬迁。CLI --data-dir 优先。
- 带圈问号必须在真实鼠标悬停时显示帮助，移出后收起，同时支持键盘聚焦；不得只靠直接发送帮助事件验收。
- 保存供应商配置后自动获取音色列表；合成创作页原“刷新音色”改为醒目的“获取音色列表”，不增加重复按钮。
- “验证格式”检查当前表单与保留的已存密钥，不要求先保存、不落盘、不调用云端；不能固定成功或忽略填写内容。
- 设置移除“导入 Web 备份到新目录”入口与说明；维护用数据复制回归不等于保留该 UI 功能。

## 2.0.0-beta.3 交互重构

- 选择数据目录后自动保存并立即使用，不要求重启，不保留独立保存目录按钮，只显示当前生效目录。
- 空目标目录由使用者选择迁移现有数据或直接使用空数据集；迁移不是保留原数据副本。迁移完成及新服务启动通过后才删除旧位置对应数据，失败保留或恢复原数据。非空目标不得覆盖。
- 豆包 1.0/2.0 在供应商选择、设置、凭据、音色和计费配置中分别呈现；按所选模型检查相应凭据。
- 缺失所选模型凭据必须在创建任务前拦截，显示明确原因和配置入口。任务页直接显示失败信息。
- 连接地址显示为 Base URL，填入官方默认地址；供应商基础地址自动补齐请求路径，也支持明确的完整请求地址。高级参数默认收起。
- 重构布局与操作顺序：合成页围绕文本、独立供应商音色、批次摘要和主操作；设置以数据目录及精简凭据为核心；主窗口、列表和任务明细统一视觉与状态反馈。
- 仅本地提交和打包，等待用户验收及明确发布通知，不创建 Tag/Release。

当前仍为预发布开发阶段，用户明确不要求旧配置、旧版本兼容，不实现配置自动迁移或兼容补丁；实际数据的锁、迁移和失败回滚属于数据安全，仍必须验证。

## 2.0.0-beta.4 接入简化

- 用户要求豆包 1.0/2.0 统一使用新 API 方式；两个模型均采用官方 V3 HTTP 单向流式接口及新版控制台 API Key，配置和音色选择继续独立，不保留旧合成接口回退。
- 移除供应商 URL、音色查询服务地址和 Cluster 输入框；火山与小米使用内置官方地址，阿里云只提供地域下拉选择，保留高级 Workspace ID，自动生成合成与音色查询地址。
- 阿里云地域选项为实际适配的北京和新加坡，不能通过列出未经适配的地域伪造支持。帮助中说明地域与 API Key 必须对应。
- 分段音频只有在成功完成后入库；WAV 使用 PCM 分段组装后生成单一文件头，后续仍按训练音频契约归一化。

## 2.0.0-beta.5 音色与播放交互

- 下拉列表固定在控件下方，屏幕空间不足时向上展开；位置、宽度不随当前选项改变，统一白色与淡紫选中样式，支持鼠标及键盘。
- 音色按中文、外语、语言未知筛选；多语种音色可以同时属于中文和外语。不猜测供应商未提供的语言。
- 音色列表突出显示名称，次级行展示性别、年龄和语言，独立标签展示指令／情感能力。整行单击勾选／取消，勾选框与文字不随选中状态缩进，空格键也可切换。
- 增加指令、情感能力筛选；豆包 2.0 提供表达指令，原生情感参数以每个音色官方目录信息为准。其他供应商按模型与音色的官方能力提供控制，不把供应商整体能力冒充每个音色的能力。
- 点击“开始合成”时检查全部所选音色与表达设置；有不支持指令的音色或格式不符时立即弹窗列出冲突，尚未创建任务、未调用云端。保留全部指令内容与勾选状态，不静默清空，不等任务失败后才提示。
- 移除全局常驻停止播放按钮；只有试听相关页面在播放时显示控制，停止／自然结束后隐藏，切换页面停止试听并取消尚未完成的播放请求。
- 样本库双击音频行直接播放，不顺带改变审核状态；审核通过显式按钮操作。选择列仅占勾选所需空间，文本与来源列优先获得宽度，选中前后保持相同换行和完整信息。

## beta.5 未发布期间的样本选择修正

用户明确未发布前继续沿用 beta.5，只有发布后才使用下一个版本号；不因本地修改或重新打包自行递增版本。

- 样本库取消独立“选择”列，勾选框直接位于文本左侧，二者之间只有正常间距，不显示额外空白焦点框。
- 单击样本整行的勾选框、文字、来源、状态或行内空白，均切换同一个样本的勾选状态；勾选框绘制位置与点击生效区域一致，不能依赖偏移的隐藏命中矩形。
- 双击选中该样本并播放，第二次点击不撤销选择；审核状态不变。空格键仍切换当前样本，跨页选择保留。
- 选中、取消、聚焦和列宽变化均保持文本正常换行及完整信息；拖动到其他行松开、点击表格空白或刷新后原位置已换为其他样本，不错误勾选。
- 勾选或取消后的首次正常绘制就同步显示整行背景和文字颜色，不等待几秒后的无关刷新；鼠标、空格键、双击与程序更新使用同一规则。只重绘受影响的可见行。
